# password-hash-wasm

A Cargo workspace of tiny Rust crates that compile to WebAssembly via
`wasm-bindgen`. They back the `password-hash-wasm` package, which the password
provider component uses to hash and verify passwords.

Each crate builds to its own `.wasm` file in `pkg/<crate>/`, and each entry point
of the package loads one of them:

- `argon2id/` wraps [`argon2`](https://docs.rs/argon2) (`password-hash-wasm/argon2id`).
- `scrypt/` wraps [`scrypt`](https://docs.rs/scrypt) (`password-hash-wasm/scrypt`).
- `scrypt-encode/` uses the PHC encoding of [`scrypt`](https://docs.rs/scrypt)
  (`password-hash-wasm/scrypt-encode`).

To add a crate, add it to `members` in `Cargo.toml` and to `crates` in the
`Justfile`, then add its entry point in `src/` and in the `exports` of
`package.json`.

## Building

Requires [`just`](https://github.com/casey/just) and the toolchain pinned in
`rust-toolchain.toml` (installed automatically by `rustup` on first use).

```sh
just test   # cargo test
just check  # compile for wasm32 (fast syntax/type check, no bindings)
just build  # regenerate pkg/ via wasm-pack (pinned version)
```

`pkg/` is gitignored and regenerated by `just build`. After changing a crate, run
`just build` (or `pnpm --filter password-hash-wasm build:wasm`) to regenerate it.

The core package depends on the version of the package published to NPM,
so that contributors don’t need to run the Rust toolchain when doing NPM-only changes.
After making changes to password-hash-wasm, manually publish the package and update the
dependency version.
