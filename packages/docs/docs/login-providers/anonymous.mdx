The anonymous provider signs a user in without asking for any credentials. It's
useful for letting people try your app before they commit to creating an
account.

## Setting up anonymous login in your app

<Steps>

<Step>

### Follow the “Getting Started” guide

First, follow the [Getting Started](../getting-started.mdx) guide:

<Cards>

- [Getting Started](../getting-started.mdx)

</Cards>

</Step>

<Step>

### Install the component

Register the anonymous component alongside the core in `convex/convex.config.ts`:

```ts file="examples/react-minimal/convex/convex.config.ts" title="convex/convex.config.ts" highlight="import anonymous from" highlight="app.use(anonymous)"

```

</Step>

<Step>

### Add a `users` table to the schema

Add an empty `users` table to your schema in `convex/schema.ts`.

Convex Auth will create a row for each account. You can also add application-specific fields to this table if necessary.

```ts file="examples/react-minimal/convex/schema.ts" title="convex/schema.ts" highlight="users: defineTable({}),"

```

</Step>

<Step>

### Set up user creation

Write a `createUser` mutation that creates a row in your `users` table and
returns its id. The provider calls it for every anonymous sign-in, since each
one establishes a new account.

```ts file="examples/react-minimal/convex/users.ts" title="convex/users.ts"

```

</Step>

<Step>

### Set up the public backend functions

Set up the anonymous provider with `setupAnonymous` and export the sign-in
mutation it hands back once you attach the callback that creates your user
rows, in `convex/auth.ts`:

```ts file="examples/react-minimal/convex/auth.ts" title="convex/auth.ts" highlight="import { setupAnonymous }" highlight="export const { signInAnonymously } = setupAnonymous(auth, {...}).attachUserCallbacks({ createUser: internal.users.createUser });"

```

</Step>

<Step>

### Set up the provider on the client

Wrap your app in `ConvexAuthProvider`, passing it the `refreshSession` and
`signOut` actions in `src/main.tsx`:

```tsx file="examples/react-minimal/src/main.tsx" title="src/main.tsx" highlight="import { ConvexAuthProvider }" highlight="<ConvexAuthProvider...>" highlight="</ConvexAuthProvider>"

```

</Step>
