Every project using Convex Auth starts with these steps.

<StepByStep>

<Step title="Install Convex Auth">

Add the Convex Auth package to your project.

:::warning

Convex Auth v2 is still in development. This installs the latest development
build from NPM.

:::

{/* prettier-ignore-start */}

<Tabs groupId="package-manager">
  <TabItem value="npm" label="npm">
    ```sh
    npm i @convex-dev/auth@beta
    ```
  </TabItem>
  <TabItem value="pnpm" label="pnpm">
    ```sh
    pnpm add @convex-dev/auth@beta
    ```
  </TabItem>
  <TabItem value="yarn" label="yarn">
    ```sh
    yarn add @convex-dev/auth@beta
    ```
  </TabItem>
  <TabItem value="bun" label="bun">
    ```sh
    bun add @convex-dev/auth@beta
    ```
  </TabItem>
</Tabs>

{/* prettier-ignore-end */}

</Step>

<Step title="Install the core component">

Register the Convex Auth component in `convex/convex.config.ts`. The guide of
each sign-in method adds more components to this file.

```ts title="convex/convex.config.ts"
import { defineApp } from "convex/server";
import auth from "@convex-dev/auth/convex.config.js";

const app = defineApp();

app.use(auth);

export default app;
```

</Step>

<Step title="Configure the authentication provider">

Create `convex/auth.config.ts`. This file tells your deployment to accept the
access tokens of Convex Auth:

```ts title="convex/auth.config.ts"
import type { AuthConfig } from "convex/server";
import { convexAuthProvider } from "@convex-dev/auth/server";

export default {
  providers: [convexAuthProvider()],
} satisfies AuthConfig;
```

Your deployment signs the access tokens with its own key, thus you do not have
secrets to configure.

</Step>

<Step title="Set up Convex Auth">

Create `convex/auth.ts`, and export the functions of the core from it. The
guide of each sign-in method adds its functions to this file.

```ts title="convex/auth.ts"
import { components } from "./_generated/api";
import { setupConvexAuth } from "@convex-dev/auth/server";

const auth = setupConvexAuth({ component: components.auth });
export const { signOut, refreshSession, isAuthenticated } = auth;
```

</Step>

</StepByStep>
