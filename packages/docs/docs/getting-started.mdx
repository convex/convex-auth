Every project using Convex Auth follows these steps.

<Steps>

<Step>

### Install Convex Auth

Add the Convex Auth package to your project:

{/* prettier-ignore-start */}

<Tabs groupId="package-manager">
  <TabItem value="npm" label="npm">
    ```sh
    npm i @convex-dev/auth@beta
    ```
  </TabItem>
  <TabItem value="pnpm" label="pnpm">
    ```sh
    pnpm add @convex-dev/auth@beta
    ```
  </TabItem>
  <TabItem value="yarn" label="yarn">
    ```sh
    yarn add @convex-dev/auth@beta
    ```
  </TabItem>
  <TabItem value="bun" label="bun">
    ```sh
    bun add @convex-dev/auth@beta
    ```
  </TabItem>
</Tabs>

{/* prettier-ignore-end */}

:::warning

Convex Auth v2 is still in development. This installs the latest development
build from NPM.

:::

</Step>

<Step>

### Run the setup command

Run the Convex Auth CLI to configure your project.

```sh
npx @convex-dev/auth
```

This command:

- Verifies you have `@convex-dev/auth` installed.
- Initializes the following files in `convex/`: `auth.config.ts`, `convex.config.ts`, `auth.ts`.

Access tokens are signed with your deployment's own key, so there are no
secrets to configure.

</Step>

<Step>

### Install a login provider

Pick a login method and follow its guide to wire it up:

<Cards>

- [Username + Password](./login-providers/password.mdx)

  Sign users in with a username and a password.

- [Username + Passkey](./login-providers/passkey.mdx)

  Sign users in with a username and a passkey.

- [Email + Password](./login-providers/email-password.mdx)

  Sign users in with an email address and a password.

- [OAuth](./login-providers/oauth.mdx)

  Sign users in with Apple, Google, or GitHub.

- [Anonymous](./login-providers/anonymous.mdx)

  Sign users in without any credentials.

</Cards>

</Step>

</Steps>
