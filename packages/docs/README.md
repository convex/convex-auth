# Convex Auth v2 — Docs

A [Docusaurus](https://docusaurus.io) site. Run the docs with:

```bash
pnpm run --filter docs dev
```

`pnpm --filter docs build` builds the static site to `build/`. Both first
generate the API reference into `docs/api` (`pnpm --filter docs api`).

## Writing docs

The pages live in `docs/`. The sidebar follows the directory: set the order
with `sidebar_position` in the frontmatter of a page, and the label and order
of a directory with its `_category_.json`.

- Link to another page by its file, for example
  `[Getting Started](../getting-started.mdx)`, never by URL. Docusaurus
  resolves file links wherever the docs are mounted, and fails the build when
  one is broken.
- Use admonitions (`:::warning`, `:::info`) for callouts, and `@theme/Tabs`
  for tabs.
- `<StepByStep>`/`<Step title="…">` and `<DocCardList items={[…]} />` have
  the names and props of the components of <https://docs.convex.dev>, and like
  there, every page has them without an import (`src/theme/MDXComponents.tsx`).
  See `src/components/` for usage. A `DocCardList` item links by URL and
  `docId`, not by file, thus moving the docs means updating those.
- Include code from the examples with an empty code block whose `file`
  names a file relative to the repository root. `highlight` picks lines by
  their content; see `src/codeInclude.mjs`:

  ````mdx
  ```ts file="examples/react-password/convex/auth.ts" title="convex/auth.ts" highlight="import { setupUsernamePassword }"

  ```
  ````

## Publishing

The docs are officially published as part of <https://docs.convex.dev>, not from
this repository. When a `v*` tag is pushed, the `Publish docs` workflow
(`.github/workflows/publish-docs.yml`) generates the API reference and exports
`docs/` with `scripts/export-docs.mjs`. The export inlines the code included
from the examples and adds a `manifest.json` that records the tag and commit.
The workflow attaches the result to the tag's GitHub Release as
`convex-auth-docs.tar.gz` with a `.sha256` checksum. To export the docs of an
existing tag again, run the workflow by hand with that tag. The site follows
the conventions of docs.convex.dev (Docusaurus 3, autogenerated sidebar, file
links), so the exported pages drop in as they are.
