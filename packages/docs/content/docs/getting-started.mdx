Every project using Convex Auth follows these steps.

<Steps>

<Step>

### Install Convex Auth

Add the Convex Auth package to your project:

{/* prettier-ignore-start */}

<Tabs items={["npm", "pnpm", "yarn", "bun"]}>
  <Tab value="npm">
    ```sh
    npm i @convex-dev/auth@beta
    ```
  </Tab>
  <Tab value="pnpm">
    ```sh
    pnpm add @convex-dev/auth@beta
    ```
  </Tab>
  <Tab value="yarn">
    ```sh
    yarn add @convex-dev/auth@beta
    ```
  </Tab>
  <Tab value="bun">
    ```sh
    bun add @convex-dev/auth@beta
    ```
  </Tab>
</Tabs>

{/* prettier-ignore-end */}

<Callout type="warn">
  Convex Auth v2 is still in development. This installs the latest development
  build from NPM.
</Callout>

</Step>

<Step>

### Run the setup command

Run the Convex Auth CLI to configure your project.

```sh
npx @convex-dev/auth
```

This command:

- Verifies you have `@convex-dev/auth` installed.
- Generates a key pair for your dev deployment (`AUTH_PRIVATE_KEY` and `AUTH_JWKS` environment variables).
- Initializes the following files in `convex/`: `auth.config.ts`, `convex.config.ts`, `auth.ts`.

</Step>
