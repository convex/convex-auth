Every project using Convex Auth follows these steps.

<Steps>

<Step>

### Set up a Convex project

Convex Auth runs on your Convex deployment, so your project needs one before
you add auth. If you haven't set up Convex yet, install it and run `npx convex
dev` once:

{/* prettier-ignore-start */}

<Tabs items={["npm", "pnpm", "yarn", "bun"]}>
  <Tab value="npm">
    ```sh
    npm i convex
    npx convex dev
    ```
  </Tab>
  <Tab value="pnpm">
    ```sh
    pnpm add convex
    pnpm exec convex dev
    ```
  </Tab>
  <Tab value="yarn">
    ```sh
    yarn add convex
    yarn convex dev
    ```
  </Tab>
  <Tab value="bun">
    ```sh
    bun add convex
    bunx convex dev
    ```
  </Tab>
</Tabs>

{/* prettier-ignore-end */}

The first run asks you to log in and to pick or create a project, then creates
your dev deployment and saves its name to `.env.local`. You can leave it
running, or stop it once it is ready.

</Step>

<Step>

### Install Convex Auth

Add the Convex Auth package to your project:

{/* prettier-ignore-start */}

<Tabs items={["npm", "pnpm", "yarn", "bun"]}>
  <Tab value="npm">
    ```sh
    npm i @convex-dev/auth@beta
    ```
  </Tab>
  <Tab value="pnpm">
    ```sh
    pnpm add @convex-dev/auth@beta
    ```
  </Tab>
  <Tab value="yarn">
    ```sh
    yarn add @convex-dev/auth@beta
    ```
  </Tab>
  <Tab value="bun">
    ```sh
    bun add @convex-dev/auth@beta
    ```
  </Tab>
</Tabs>

{/* prettier-ignore-end */}

<Callout type="warn">
  Convex Auth v2 is still in development. This installs the latest development
  build from NPM.
</Callout>

</Step>

<Step>

### Run the setup command

From the root of your project, run the Convex Auth CLI to configure your
project. It sets environment variables on the deployment you created in the
first step.

```sh
npx @convex-dev/auth
```

This command:

- Verifies you have `@convex-dev/auth` installed.
- Generates a key pair for your dev deployment (`AUTH_PRIVATE_KEY` and `AUTH_JWKS` environment variables).
- Initializes the following files in `convex/`: `auth.config.ts`, `convex.config.ts`, `auth.ts`.

</Step>
